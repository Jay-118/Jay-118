## 🚀 项目

**HunterAgent — 自动化渗透测试资产测绘与指纹识别智能体**（独立开发）

基于 LangChain 框架，由本地微调 LLM 自主调度 20+ 安全工具，自动研判组件、真实目标 IP、
开放端口等潜在攻击面，打通资产测绘 → 风险识别 → 结果整理全流程，整体渗透效率提升 2–3 倍。

**哈尔滨工程大学授权渗透测试与安全评估**

对校内多个信息系统开展授权渗透测试，挖掘严重漏洞 1 个、高危漏洞 1 个及中低危若干，并输出修复建议。
